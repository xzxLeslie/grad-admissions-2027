# 2027 港美新 CS/EE 硕博申请导航（本地网页）

纯静态站点，**无需安装、无需联网即可浏览已收录内容**（点开官方链接时需要网络）。

## 如何打开

1. 双击 `index.html`，或
2. 在文件夹地址栏输入后回车用浏览器打开。

## 如何分享

把整个 `grad-admissions-2027` 文件夹打成 zip 发给对方即可。对方解压后打开 `index.html`。

也可直接使用上级目录的 `grad-admissions-2027-share.zip`（更新数据后请重新打包）。

## 结构

- `index.html` — 主页面
- `css/styles.css` — 样式
- `js/data.js` — 全部项目数据（由 `build_data.py` 生成）
- `js/app.js` — 筛选 / 详情交互
- `build_data.py` — 重新生成数据

## 分区说明

- **香港 / 新加坡 / 美国** 一级切换
- **PhD / 硕士** 二级切换
- 香港侧可再筛 **本校 vs 内地分校**

## 新加坡收录（摘要）

- **SINGA** 全奖博士（Aug 2027 截止 2026-12-01）
- **NUS** Computing PhD / ECE PhD / MComp & MComp AI 等
- **NTU** CCDS PhD / EEE PhD / MSc AI·DS·Cyber
- **SMU** SCIS PhD / MITB 等硕士
- **SUTD** PhD / MEng / AI 相关 MSc
- **SIT** PhD / 硕士（门户核对）

## 数据说明

- 美国约 **98 所** CS 相关院校（PhD + 硕士各一条）
- 香港本校 + 内地分校；HKPFS **不适用于**内地分校
- 提交申请前请再核对官方系统
